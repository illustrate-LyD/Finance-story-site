# 人生场景时间线：最小 IA 与落地说明（2026-11-22）

给 Nibble 今晚落地。设计范围只加这条读法，**不拆现有系列，不重做深浅色主题**，沿用 Cool Ink Press D + 方案 B 表面 token。

读者仍是有一点投资经验的人；语气与现有故事站一致。内容与难度由 Bullie 定稿。

---

## 1. 决定（先看这个）

人生场景是**一条时间线索引**，不是第 8 个系列，也不是第 4 条筛选轴。

- 现有系列卡、系列页、`seriesSlug` 规则全部保留。每篇故事仍然**恰好属于一个系列**。
- 时间线只是按人生阶段把若干篇**按顺序挂起来**。已有篇只挂上，不改写、不改系列。
- 不要在首页系列栅格里加一张「人生场景」SeriesCard，以免和「场景」计数混在一起。
- 不要新增 `?life=` / `?stage=` 筛选，FilterBar 今晚不动。
- 路由：**`/life/`**。导航文案：**人生**。页面标题：**人生场景**。

## 4. 数据

新建 `content/life-timeline.json`（已放一份样例，结构以该文件为准）。构建时读取：

- `stops[]` 按数组顺序渲染。
- 用 `storySlug` 查 `content/stories/<slug>.md`：
  - **有正文页** → 该站为「可读」：标题、摘要、难度、系列名一律取故事 frontmatter（不要用手写 teaser 覆盖标题）。
  - **无正文页** → 该站为「预告」：标题用 `teaser`，难度用 `plannedDifficulty`，**不要**链到 `/story/<slug>/`。
- `sameAs`：指向另一站的 `id`。第 6 站必须显示「与「出生到 18 岁」为同一篇」。
- 不要把「同一篇出现两次」写成两篇预告或两篇可读。去重按 slug。

新稿尚未到来时：请把尚未成文的 5 个新 slug（`life-child-dca-account`、`life-graduation-plan`、`life-marriage-house-car`、`life-after-marriage-allocation`、`life-retirement-legacy`）写入 `planned-stories.json`（系列与难度同上表），这样对应系列页的「接下来」也能看见。等 MD 到位，预告按现有规则自动消失。《雨伞不是摇钱树》不要再写入预告。

建议 tags（供 Bullie / 预告用，不挡上线）：孩子定投、毕业规划、婚后配置 `投资`；结婚房车 `投资`；养老 `投资`。保险篇已有 `保险`。

## 5. 页面结构

### 5.1 `/life/`

```
[AppBar：首页  系列▾  人生  索引  主题]
[页头]
  眉题（eyebrow，accent）：人生路径
  H1（衬线 600）：人生场景
  导语：按时间顺序走一遍常见人生节点。每篇仍留在原来的系列里，这里只是另一条读法。
  数字行（.small）：7 个阶段 · {唯一可读 slug 数} 篇可读 · {唯一预告 slug 数} 篇预告
[垂直时间线 .life-timeline]
  每个 .life-stop：左轴 + 卡片
[Footer：非投资建议声明]
```

`/life/` **不要** FilterBar。

数字规则：

- 「7 个阶段」= `stops.length`（出现两次的那一篇仍占两个阶段）。
- 可读 / 预告按 **唯一 slug** 计，与全站 §7 名词一致。
- 构建时写入，禁止手写死数；全为预告时仍显示，例如 `7 个阶段 · 1 篇可读 · 5 篇预告`（因为保险篇已在）。

### 5.2 首页区块 `#life-path`

```
[眉题：人生路径]
[H2 衬线 600：按人生阶段读]          [右侧数字：7 个阶段 · M 篇可读 · K 篇预告]
[同一条垂直时间线，卡片更紧凑：阶段名 + 标题 + LevelBadge + 进入/预告]
[块底文本链] 查看完整时间线 →   指向 /life/
```

7 站全部画出（阶段不多，不必再截成 3 站预览）。首页卡片可省略摘要，完整页保留摘要。间距、标题级与现有 `.section` 一致。

### 5.3 时间线组件 `.life-timeline` / `.life-stop`

结构（每站一行）：

```
[轴]  竖线（1–2px border-subtle）+ 圆点
[卡]  阶段名（eyebrow，0.78rem / 700 / accent 或 secondary）
      标题（1.05–1.15rem，可读为链接，预告为 span）
      摘要（仅 /life/，0.9rem secondary；首页可省）
      底行：LevelBadge + 所属系列 Chip + 「同一篇」说明 + 右下「进入 →」
```

状态：

| 状态 | 表现 |
|------|------|
| 可读 | 卡片：`--bg-surface` + `--border-subtle` + radius-md。圆点实心 accent 或 primary。标题可点，进 `/story/<slug>/`。「进入 →」同现有系列卡。系列 Chip 点进 `/series/<seriesSlug>/`。 |
| 预告 | 卡片：`--bg-muted` + **dashed** 边，与现有 `.planned` 一致。圆点空心 / muted。标题不是链接。右下徽章「预告」，无假链。 |
| 同一篇（第 6 站） | 标题可与第 1 站相同（取故事标题）。在标题下或底行加 `.small`：「与「出生到 18 岁」为同一篇」。不要复制成两条看起来不像同一篇的文案。 |
| 故事页「当前」 | 本篇对应的站（孩子定投则两站都算）左侧 3px accent 条，与 `.featured-pick` 同类，不要外发光。 |

轴在窄屏保留，卡片全宽。桌面轴在左，卡在右，时间线最大宽跟 `.container`。卡片默认无阴影。hover：可读卡边可略亮，不要新阴影体系。

难度：**只用现有 LevelBadge**（L1 入门 / L2 进阶 / L3 精读，颜色走现有 `--level-*`）。时间线本身没有难度。预告站也要出示 `plannedDifficulty`。不要为人生路径另做一套徽章，也不要在 `/life/` 做难度筛选。

## 6. 故事页「人生路径」模块

选择器建议：`.life-path-nav`，放在正文完成后、「继续读这个系列」**上方**（不要插进故事正文）。

```
人生场景
[迷你时间线：七个阶段名，当前站强调；孩子定投篇则强调第 1 和第 6 站]
上一阶段：《标题》  |  下一阶段：《标题》
```

- 上一 / 下一按 **stops 数组顺序**，不是按系列。
- 邻站可读：文本链到该故事。
- 邻站预告：阶段名 +「预告」，不可点。
- 已是第一站：隐藏「上一阶段」；最后一站隐藏「下一阶段」。
- 另给一条文本链「查看完整时间线」→ `/life/`。
- 系列相关推荐规则不变。结婚这篇的相关里应能自然出现 `mortgage-leverage`（同系列优先即可）。
