# IA：场景 × 标签 × 难度

读者：有一点投资经验；全文中文。

## 三轴与内容

1. 场景：每篇恰好一个。首发 `markets-cycles` 市场与周期、`first-paycheck` 第一笔工资、`home-and-debt` 买房与负债；另三个规划系列列卡预告。
2. 标签：可多选「投资 / 保险 / 宏观 / 微观 / 交易」。
3. 难度：内容保持 Bullie 的 L1/L2/L3，展示层为「入门 / 进阶 / 精读」。

## 路由

| 路由 | 页面 | 说明 |
|---|---|---|
| `/` | 首页 | Hero、系列卡、人生阶段入口、五标签快捷、精选故事 |
| `/series/<slug>/` | 系列 | 场景锁定、标签多选、难度单选、故事与预告、空态 |
| `/story/<slug>/` | 故事 | 故事 → 术语表 → 实例 → 可选「带走这几句」 |
| `/life/` | 人生场景 | 按人生阶段排列的时间线索引，不是新系列；详见 `docs/LIFE_TIMELINE.md` |
| `/terms/` | 索引 | 术语扁平列表、同筛选器、反查故事 |

统一查询：`?scene=&tag=&difficulty=`；tag 可重复或逗号分隔，difficulty 为 L1/L2/L3 或空。变更写 URL，刷新保持。

详见 `docs/CONTENT_SCHEMA.md`、`docs/DESIGN_HANDOFF.md`。


## 篇型

- `format: story`（默认）：寓言；Toc「故事 / 术语表 / 实例 / 带走这几句」
- `format: brief`：理念笔记；Toc「**理念** / 术语表 / …」；卡片角标「理念」


## 人生场景时间线（2026-11-22）

人生场景是**一条时间线索引**（`/life/`），不是第 8 个系列，也不进入筛选轴。每篇故事仍恰好属于一个现有系列；时间线只按阶段顺序把篇目挂上。已有《雨伞不是摇钱树》只挂不改；《给孩子定投》在「出生到 18 岁」与「生孩子」出现两次，但是同一篇。难度仍用「入门 / 进阶 / 精读」徽章，时间线本身没有难度。

入口：导航「人生」、首页系列栅格下「按人生阶段读」、相关系列页一句提示、挂在时间线上的故事页底部路径模块。完整落地说明见 `docs/LIFE_TIMELINE.md`。
